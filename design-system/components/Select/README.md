# Select

Lista de escolha nativa com a cara dos campos: escolher o modelo de IA, o nível, a matéria.

- `options`: textos ou `{ value, label, disabled }`. `size` `md` (padrão) ou `sm` (32px, em barras de ferramenta — o texto vira mono).
- Até ~7 opções. Para 2–4 opções que o usuário precisa comparar, prefira `RadioGroup`.
