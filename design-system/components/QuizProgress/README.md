# QuizProgress

Placar do questionário: "QUESTÃO 04/10", o tempo e uma fileira de blocos tipo LED.

- `total`, `current` (começa em 1), `results` por questão (`correct`, `incorrect`, `partial`, `skipped`), `time` e `label`.
- Os estados não dependem só da cor: errada vira uma barra baixa, pulada fica tracejada, parcial é creme claro, atual é âmbar.
- Fica no topo da tela de questionário, na largura da coluna.
