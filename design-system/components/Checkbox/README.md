# Checkbox

Caixa quadrada para ligar opções independentes num formulário; marcada fica âmbar com o visto escuro.

- `label` (obrigatório), `description` opcional, e as props de `<input type="checkbox">` (`checked`, `defaultChecked`, `onChange`, `disabled`).
- Para efeito imediato (preferência que vale na hora) use `Switch`; Checkbox é para o que só vale ao salvar.
