# EmptyState

Tela vazia com um bloco-pôster de ideograma: diz o que falta e oferece a única ação que resolve.

- Passe `title` (o que não existe ainda), `children` (para que serve, uma frase), `action` (normalmente um `Button` primário), `glyph` (padrão 学) e `tone` do bloco (padrão `brick`).
- Combine o ideograma com o assunto: sem cadernos → 書, sem cursos → 学, sem questionários → 問, tudo revisado → 完.
- Empilha no celular.
