# EssayAnswer

Questão dissertativa: enunciado, campo grande com contador e o botão de enviar para correção.

- `prompt`, `value`/`defaultValue`/`onChange`, `onSubmit(texto)`, `submitting` (mostra "Corrigindo…"), `minLength` (libera o envio só depois do mínimo e avisa quanto falta), `maxLength`, `hint`, `submitLabel`.
- Mesmo cabeçalho do `QuizQuestion` (`number`, `total`, `kicker`).
- Depois da correção, mostre `QuizFeedback` com `status="partial"`, a nota e os critérios.
