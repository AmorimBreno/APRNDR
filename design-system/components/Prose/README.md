# Prose

Estilo de leitura para conteúdo gerado: o markdown já renderizado dos blocos da aula, dos resumos e dos cadernos.

- Envolva o HTML do markdown em `<Prose>` (`size="lg"` 17/28 padrão; `md` 15/24 em painéis estreitos). O `LessonBlock` já aplica sozinho, no tamanho `lesson-body` (19/32).
- Cobre h2–h4, parágrafos, negrito, itálico, links (`amber` sublinhado), listas (marcador quadrado âmbar), código inline e em bloco (`surface-well`), citação (Fraunces itálica com aspas âmbar), tabela, `mark` (trecho selecionado) e imagens.
- O conteúdo nunca vira caixa-alta: variáveis e siglas ficam como o tutor escreveu.
- Largura de leitura: até `measure-read` (720px).
