# StudentNote

A sua intervenção na aula — uma pergunta, uma resposta, um "não entendi" — como um bilhete creme colado à direita da página, levemente torto.

- `label` ("Você perguntou", "Você pediu", "Sua resposta", "Você anexou"), `children` (o texto), `attachments` (arquivos enviados naquele momento).
- Aparece na coluna da aula logo depois que você manda algo pela `AskBar`; o próximo `LessonBlock` do tutor responde a ela.
- Nada de balão de chat: é uma nota dentro do documento.
