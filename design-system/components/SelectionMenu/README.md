# SelectionMenu

Barra creme que aparece sobre um trecho selecionado da explicação: reexplicar só aquele trecho, pedir um exemplo, anotar no caderno.

- `actions`: `{ label, icon, onClick }`. Quem usa posiciona (absoluto, centralizado acima da seleção; a setinha aponta para baixo) e mostra/esconde conforme a seleção.
- Marque o trecho com `<mark>` dentro do `Prose` enquanto a barra estiver aberta.
- Até três ações.
