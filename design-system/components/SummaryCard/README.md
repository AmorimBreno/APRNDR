# SummaryCard

O arquivo de resumo gerado no fim da aula, para revisar depois: bloco `moss` com o ideograma 復習 (revisão) numa caixa, nome, ações e uma ficha com leituras.

- `title` ("Aula 07 — Derivadas"), `kicker` (padrão "Resumo gerado"), `stats` (`{ label, value, unit }`: blocos, perguntas, acertos), `onOpen` e `onDownload` (com `openLabel`, `downloadLabel`), `glyph`.
- Entra no fim da coluna da aula quando você encerra; a `AskBar` sai de cena.
