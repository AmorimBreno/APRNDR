# RadioGroup

Grupo de opções exclusivas com legenda em letra de painel: nível, objetivo, "teórico ou aplicado".

- `legend` (a pergunta), `options` (`{ value, label, description, disabled }`), `value`/`defaultValue`, `onChange(value)`, `orientation` `vertical` (padrão) ou `horizontal` para opções curtas.
- Sempre deixe uma opção marcada quando houver um padrão razoável.
- Para perguntas de questionário (com letra e gabarito) use `QuizQuestion`.
