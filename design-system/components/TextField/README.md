# TextField

Campo de uma linha com rótulo de painel em cima, ajuda ou erro embaixo.

- `label`, `hint`, `error` (troca a ajuda e pinta a borda de `brick-text`), `icon` à esquerda, `size` `md` (40px) ou `lg` (48px), e todas as props de `<input>`.
- Rótulo curto em linguagem normal ("Nome do curso"); o caixa-alta vem do estilo. Placeholder só como exemplo ("Ex.: Cálculo I"), nunca no lugar do rótulo.
- Erro diz como corrigir: "Cole o link completo, começando com https://".
