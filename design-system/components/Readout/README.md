# Readout

Leitura técnica: legenda de painel à esquerda, uma setinha ▸ e o valor numa caixa de traço grosso, como "QUESTÕES RESTANTES ▸ [12]".

- `label` (até duas linhas), `value`, `unit` ("min", "%").
- Herda a cor do bloco: empilhe dentro de `SpecBox` ou direto num `Card`, com `space-3` de vão.
- Números com vírgula decimal ("2,47").
